# رفقة الإنجاز 🌿 (Rifqa Al-Injaz)
### تطبيق إدارة المهام اليومية، الختمات الجماعية والفردية، والورد اليومي مع إشعارات الدفع الخارجية (FCM)

تطبيق متكامل مبني باستخدام React + TypeScript + Tailwind CSS و Firebase (Firestore & Authentication)، ومجهز للعمل كتطبيق هاتف أصيل لنظامي **Android (APK)** و **iOS (iPhone)** عبر **Capacitor**.

---

## 📱 محتويات ومميزات التطبيق
1. **المهام الفردية الخاصة والأوراد**: ختمة خاصة بك وأوراد بأوقات محددة وتذكيرات خاصة.
2. **المهام والمجموعات الجماعية**: توزيع دوري، متابعة تقدم الأعضاء، ولوحة تحفيزية.
3. **مصحف وقارئ إلكتروني مدمج**: استعراض القرآن الكريم وحفظ مواضع القراءة.
4. **إشعارات دفع خارجية حقيقية (FCM / APNs)**: إشعارات تصل إلى الهاتف حتى والتطبيق مغلق وشاشة الهاتف مقفلة.
5. **بناء آلي للـ APK عبر GitHub Actions**: بمجرد رفع الكود لمستودعك على GitHub، يقوم سير العمل ببناء ملف `app-debug.apk` تلقائياً لتنزيله مباشرة!

---

## 🚀 طريقة التشغيل المحلي والبناء

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. التشغيل في وضع التطوير:
```bash
npm run dev
```

### 3. بناء المشروع وتحديث منصات الهاتف (Capacitor):
```bash
npm run build:cap
```

---

## 🤖 بناء تطبيق أندرويد (Android APK)

1. حمّل ملف `google-services.json` من لوحة تحكم Firebase لمشروعك (حزمة التطبيق المعرفة هي `com.rifqa.app`).
2. ضع الملف في المسار:
   ```
   android/app/google-services.json
   ```
3. افتح المشروع في أندرويد ستوديو:
   ```bash
   npm run cap:android
   ```
4. من شريط أندرويد ستوديو العلوي:
   اختر **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
5. سيتم استخراج ملف الـ APK الجاهز للتثبيت على هاتفك في:
   `android/app/build/outputs/apk/debug/app-debug.apk`

---

## 🍏 بناء تطبيق آيفون (iOS)

1. حمّل ملف `GoogleService-Info.plist` من Firebase.
2. ضعه داخل مجلد `ios/App/App/`.
3. افتح المشروع في Xcode (على نظام macOS):
   ```bash
   npm run cap:ios
   ```
4. اختر جهازك أو المحاكي واضغط **Run (Cmd + R)** أو **Product > Archive**.

## 🔔 إعداد إشعارات الدفع الخارجية (FCM)

- تم إدماج حزمة `@capacitor/push-notifications` رسمياً.
- عند تشغيل التطبيق على الهاتف لأول مرة، يُطلب إذن الإشعارات من النظام مباشرة.
- يتم تسجيل رمز الجهاز وتخزينه في Firebase Firestore تحت مستند المستخدم.
- لإرسال إشعار فوري: توجه إلى **Firebase Console** > **Messaging** > **New Campaign** > **Notifications** وأرسل إشعارك ليصل فوراً إلى جميع الأجهزة أو إلى رمز جهاز محدد!

## 🐙 حفظ المشروع ورفعه على GitHub

لرفع هذا المشروع إلى حسابك في GitHub، نفّذ الأوامر التالية في سطر الأوامر (Terminal):

```bash
# 1. تهيئة المستودع (إذا لم تكن مهيأة)
git init

# 2. إضافة جميع الملفات
git add .

# 3. حفظ الالتزام
git commit -m "إطلاق تطبيق رفقة الإنجاز لنظامي أندرويد وiOS مع إشعارات FCM"

# 4. ربط المستودع بمستودعك على GitHub (استبدل USERNAME باسم حسابك و REPO باسم المستودع)
git remote add origin https://github.com/USERNAME/rifqa-app.git

# 5. رفع الكود إلى الفرع الرئيسي main
git branch -M main
git push -u origin main
```

## 🛠 البناء التلقائي عبر GitHub Actions (CI/CD)
يحتوي المشروع على ملف جاهز في المسار:
`.github/workflows/build-apk.yml`

بمجرد رفع الكود إلى GitHub:
1. اذهب إلى تبويب **Actions** في صفحة مستودعك على GitHub.
2. ستجد البناء التلقائي يعمل.
3. فور انتهائه (خلال 3-4 دقائق)، حمّل ملف الـ APK المسمى **Rifqa-Android-APK** مباشرة إلى هاتفك وثبته فوراً دون الحاجة لتثبيت أي برامج على حاسوبك!
